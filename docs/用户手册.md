# 抖音评论情感分析系统 - 用户手册

## 1. 系统简介

### 1.1 系统概述
抖音评论情感分析系统是一个专业的数据分析平台，能够对抖音视频评论进行深度分析，包括情感分析、趋势分析、词云分析和地区分布分析等。系统采用先进的机器学习算法，帮助用户快速了解评论的情感倾向和变化趋势。

### 1.2 主要功能
- **情感分析**：分析评论的情感倾向（正面、负面、中性）
- **情感趋势分析**：展示情感随时间的变化趋势
- **词云分析**：生成评论关键词词云图
- **地区分布分析**：统计评论用户的地域分布
- **数量趋势分析**：展示评论数量的时间趋势
- **报告生成**：生成包含图表和AI分析的综合报告

### 1.3 适用人群
- 市场营销人员：了解用户对产品的反馈
- 内容创作者：分析观众对视频的评论
- 研究人员：进行社交媒体数据分析
- 企业管理者：监控品牌舆情

## 3. 功能介绍

### 3.1 情感分布分析

#### 3.1.1 功能说明
情感分布分析可以统计评论中正面、负面、中性评论的数量和占比，帮助用户快速了解评论的整体情感倾向。

#### 3.1.2 使用步骤
1. 在左侧导航栏点击"情感分布分析"
2. 在下拉菜单中选择要分析的视频
3. 选择情感分析模型（随机森林、朴素贝叶斯等）
4. 点击"分析"按钮
5. 查看分析结果

#### 3.1.3 结果展示
- **情感分布饼图**：展示正面、负面、中性评论的占比
- **情感分布柱状图**：展示各情感类别的具体数量
- **统计卡片**：显示正面、负面、中性评论的数量和占比

#### 3.1.4 交互功能
- 点击情感卡片可以查看对应类别的具体评论
- 点击评论列表中的评论可以查看详细信息
- 支持按情感类型筛选评论

### 3.2 情感趋势分析

#### 3.2.1 功能说明
情感趋势分析可以展示评论情感随时间的变化趋势，帮助用户了解情感变化规律。

#### 3.2.2 使用步骤
1. 在左侧导航栏点击"情感趋势分析"
2. 在下拉菜单中选择要分析的视频
3. 选择时间维度（按天/按月）
4. 选择情感分析模型
5. 点击"分析"按钮
6. 查看分析结果

#### 3.2.3 结果展示
- **情感趋势折线图**：展示正面、负面、中性评论随时间的变化
- **统计信息**：显示总评论数和各情感类别的数量
- **趋势分析**：AI分析情感变化趋势

#### 3.2.4 时间维度说明
- **按天**：每天的情感分布情况，适合短期分析
- **按月**：每月的情感分布情况，适合长期分析

### 3.3 关键词分析

#### 3.3.1 功能说明
关键词分析可以提取评论中的高频词汇，生成词云图，帮助用户了解评论的主要内容。

#### 3.3.2 使用步骤
1. 在左侧导航栏点击"关键词分析"
2. 在下拉菜单中选择要分析的视频
3. 设置最小出现次数（默认为3）
4. 点击"分析"按钮
5. 查看分析结果

#### 3.3.3 结果展示
- **词云图**：以词云形式展示高频关键词
- **关键词列表**：按频率排序的关键词列表
- **词频统计**：显示每个关键词的出现次数

#### 3.3.4 词云图说明
- 词的大小表示出现频率
- 词的颜色随机分配
- 支持鼠标悬停查看词频

### 3.4 地区分布分析

#### 3.4.1 功能说明
地区分布分析可以统计评论用户的地域分布，帮助用户了解用户的地理分布特征。

#### 3.4.2 使用步骤
1. 在左侧导航栏点击"地区分布分析"
2. 在下拉菜单中选择要分析的视频
3. 设置最小评论数（默认为3）
4. 点击"分析"按钮
5. 查看分析结果

#### 3.4.3 结果展示
- **地区分布图**：以柱状图展示各地区评论数量
- **地区列表**：按评论数排序的地区列表
- **统计信息**：显示总评论数和覆盖地区数

#### 3.4.4 数据说明
- 地区信息来源于评论用户的IP地址
- 只统计评论数大于等于最小值的地区
- 支持按评论数排序

### 3.5 报告生成

#### 3.5.1 功能说明
报告生成功能可以将多个分析结果整合成一个完整的HTML报告，包含图表和AI智能分析。

#### 3.5.2 使用步骤
1. 在左侧导航栏点击"报告生成"
2. 在下拉菜单中选择要生成报告的视频
3. 勾选需要包含的分析内容：
   - 数量趋势
   - 情感分析
   - 情感趋势分析
   - 评论词云图
   - 分布地区
4. 配置各分析模块的参数
5. 点击"生成报告"按钮
6. 查看报告预览
7. 点击"下载报告"保存报告

#### 3.5.3 报告内容
- **标题**：视频标题和分析时间
- **分析图表**：各类分析的图表展示
- **AI分析**：通义千问API生成的智能分析
- **数据统计**：各类分析的统计数据

#### 3.5.4 报告格式
- HTML格式，可在浏览器中打开
- 包含所有图表和分析结果
- 支持打印和分享

## 4. 操作指南

### 4.1 数据采集

#### 4.1.1 爬取评论
1. 登录系统后，进入"视频管理"页面
2. 点击"添加视频"按钮
3. 输入抖音视频链接
4. 设置最大评论数（可选）
5. 点击"爬取评论"按钮
6. 等待爬取完成

#### 4.1.2 注意事项
- 确保视频链接正确
- 爬取时间取决于评论数量
- 爬取完成后数据会自动保存

### 4.2 数据管理

#### 4.2.1 视频管理
1. 进入"视频管理"页面
2. 查看所有已爬取的视频
3. 可以查看视频详情、编辑视频信息、删除视频
4. 支持按关键词搜索视频

#### 4.2.2 评论管理
1. 进入"评论列表"页面
2. 选择要查看的视频
3. 查看该视频的所有评论
4. 支持按情感类型筛选评论
5. 支持按关键词搜索评论

### 4.3 用户管理（管理员）

#### 4.3.1 查看用户列表
1. 进入"用户管理"页面
2. 查看所有注册用户
3. 支持按关键词搜索用户
4. 支持分页查看

#### 4.3.2 创建用户
1. 点击"添加用户"按钮
2. 填写用户信息
3. 选择用户角色（管理员/普通用户）
4. 点击"保存"按钮

#### 4.3.3 编辑用户
1. 在用户列表中找到要编辑的用户
2. 点击"编辑"按钮
3. 修改用户信息
4. 点击"保存"按钮

#### 4.3.4 删除用户
1. 在用户列表中找到要删除的用户
2. 点击"删除"按钮
3. 确认删除操作

#### 4.3.5 批量导入用户
1. 点击"批量导入"按钮
2. 下载用户模板Excel文件
3. 按照模板格式填写用户信息
4. 上传填写好的Excel文件
5. 点击"导入"按钮

### 4.4 账户设置

#### 4.4.1 修改密码
1. 点击右上角的用户名
2. 选择"修改密码"
3. 输入旧密码和新密码
4. 点击"确认"按钮

#### 4.4.2 退出登录
1. 点击右上角的用户名
2. 选择"退出登录"
3. 系统会跳转到登录页面

## 5. 常见问题

### 5.1 登录问题

**Q: 忘记密码怎么办？**
A: 目前系统不支持密码找回功能，请联系管理员重置密码。

**Q: 登录时提示"用户名或密码错误"？**
A: 请检查用户名和密码是否正确，注意大小写。

**Q: 登录后自动退出？**
A: 可能是token过期，请重新登录。

### 5.2 数据分析问题

**Q: 分析时提示"数据不存在"？**
A: 请确保已经爬取了该视频的评论数据。

**Q: 分析结果不准确？**
A: 可以尝试更换不同的机器学习模型，不同模型可能有不同的准确率。

**Q: 词云图显示乱码？**
A: 请确保系统安装了中文字体，或联系管理员检查字体配置。

**Q: 趋势图没有数据？**
A: 请检查评论数据中是否包含日期信息。

### 5.3 报告生成问题

**Q: 报告生成失败？**
A: 请确保勾选了至少一个分析内容，并且视频数据存在。

**Q: 报告中的AI分析为空？**
A: 可能是通义千问API调用失败，请稍后重试。

**Q: 报告下载失败？**
A: 请检查浏览器下载设置，或尝试使用其他浏览器。

### 5.4 性能问题

**Q: 分析速度很慢？**
A: 分析速度取决于数据量，数据量越大，分析时间越长。

**Q: 页面加载缓慢？**
A: 请检查网络连接，或清理浏览器缓存。

**Q: 系统卡顿？**
A: 可能是服务器负载过高，请稍后重试。

### 5.5 其他问题

**Q: 如何联系技术支持？**
A: 请通过系统提供的联系方式联系技术支持团队。

**Q: 系统支持哪些浏览器？**
A: 推荐使用Chrome、Firefox、Edge等现代浏览器。

**Q: 可以在手机上使用吗？**
A: 系统支持响应式设计，可以在手机浏览器中使用。

## 6. 最佳实践

### 6.1 数据采集建议
1. **定期采集**：建议定期采集评论数据，保持数据更新
2. **合理设置评论数**：根据需求设置合理的最大评论数，避免数据量过大
3. **验证数据质量**：采集后检查数据质量，确保数据完整

### 6.2 数据分析建议
1. **多模型对比**：使用不同的机器学习模型进行对比，选择最合适的模型
2. **多维度分析**：结合情感分析、趋势分析、词云分析等多个维度进行综合分析
3. **关注异常值**：注意分析结果中的异常值，可能包含重要信息

### 6.3 报告生成建议
1. **选择合适的内容**：根据报告目的选择合适的分析内容
2. **配置合理参数**：根据数据特点配置合理的分析参数
3. **定期生成报告**：定期生成报告，跟踪数据变化趋势

### 6.4 数据安全建议
1. **保护账户安全**：不要泄露账户密码，定期修改密码
2. **数据备份**：重要数据建议定期备份
3. **权限管理**：合理分配用户权限，避免数据泄露
